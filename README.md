## Estudio de caso 2 — Análisis y modelamiento de datos en R

## Descripción
Este proyecto estudia la relación entre el precio de venta de casas y apartamentos en Bogotá 
y características de los inmuebles, como el área, el número de habitaciones, el número de baños, 
el tipo de vivienda y su ubicación. Para ello se exploran los datos y se comparan cinco modelos 
de regresión lineal, siguiendo las actividades desarrolladas en clase.
